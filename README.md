## El rumor

Juego para 6.º: cómo se propaga un rumor en una red y cómo se frena. Publicado en https://gastonbieito.github.io/rumor/

`npm run build` arma `docs/index.html` (y `dist/`). `node tools/verify.mjs` verifica que cada nivel se pueda ganar con 3 estrellas. `npm test` juega los 8 niveles en Edge y Chrome.

Atajo docente: Shift + D abre todos los niveles.
